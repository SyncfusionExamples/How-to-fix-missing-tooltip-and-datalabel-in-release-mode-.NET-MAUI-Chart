KB Title Expectation:
Why Tooltip and DataLabel Are Not Showing in Release Mode in .NET MAUI Charts?

Description:
Issue: In .NET MAUI applications using SfCartesianChart, developers observe that tooltips and data labels display correctly in Debug mode but fail to show binding values in Release mode on Android and iOS.

Solution: https://support.syncfusion.com/agent/tickets/775908#update-7807905
Steps to Fix:
Use a Converter for Tooltip/DataLabel Binding
Define a converter to extract values from your model.

Apply [Preserve(AllMembers = true)] Attribute
Add this attribute to your data model and view model to prevent linker trimming.

Bind Tooltip/DataLabel Using the Converter
Ensure your XAML uses the converter correctly in the tooltip or data label template.

This is solution given to customer:

We would like to inform you that, after the release of .NET 9.0, compiled bindings introduced with x:DataType make the tooltip’s content use its own type scope, so it cannot access the user item model. but for getting the item from tooltipInfo class we have to specify the x:DataType="chart:TooltipInfo".
 
Secondly, Release mode builds enable trimming/AOT, which can strip properties referenced only from XAML. As a result, it works in Debug mode but not in Release mode.
 
We recommend using the workaround below and we’ll work toward refining this fix in a future update.
 
 
<chart:SfCartesianChart x:Name="chart">
        <chart:SfCartesianChart.Resources>
            <local:TooltipConverter x:Key="tooltipConverter"/>
            <DataTemplate x:Key="tooltiptemplate">
                <StackLayout x:DataType="chart:TooltipInfo" Orientation="Vertical">
                    <Label Text="{Binding Item, StringFormat='Planned :  {0}h', Converter={StaticResource tooltipConverter },ConverterParameter='Planned'}"
                          TextColor="White" />
                </StackLayout>
            </DataTemplate>
        </chart:SfCartesianChart.Resources>
        <chart:SplineAreaSeries x:Name="series"
                                                   ItemsSource="{Binding ChartData }"
                                                   XBindingPath="WeekNumber"
                                                   YBindingPath="Planned"
                                                   EnableTooltip="True"
                                                   TooltipTemplate="{StaticResource tooltiptemplate}"/>
</chart:SfCartesianChart>

 
 
public class TooltipConverter : IValueConverter
    {
        public object? Convert(object? value, Type targetType, object? parameter, CultureInfo culture)
        {
            if (value is Model model)
            {
                switch (parameter?.ToString())
                {
                    case "Planned":
                        return model.Planned;
                }
            }
            return value;
        }
        public object? ConvertBack(object? value, Type targetType, object? parameter, CultureInfo culture)
        {
            return value;
        }
   }

 
Preserve your data model so reflection-based access isn’t trimmed.
 
[Preserve(AllMembers = true)]
    public class ViewModel
    {
        public ObservableCollection<Model> ChartData { get; set; } = new()
        {
        new Model { WeekNumber = 1, Planned= 3 },
        new Model { WeekNumber = 2, Planned= 5 },
        new Model { WeekNumber = 3, Planned= 2 },
        new Model { WeekNumber = 4, Planned= 5 },
        new Model { WeekNumber = 5, Planned= 7 },
        };
    }

    [Preserve(AllMembers = true)]
    public class Model
    {
        public double WeekNumber { get; set; }
        public double Planned { get; set; }
    }

 
We were able to render the tooltip content in Release mode by using a converter.
